# KomicTranslate - dipendenze runtime, variante macOS (ARM + Intel)
#
# Derivata da requirements-cpu.txt con queste differenze:
#   - NESSUN extra-index CUDA, NESSUN suffisso +cu121 (torch da PyPI standard,
#     su Mac usa CPU/MPS, mai CUDA/NVIDIA).
#   - Aggiunti pyobjc-framework-Cocoa/WebKit con marker sys_platform=="darwin":
#     servono a pywebview su macOS (WebKit nativo). Su Windows/Linux pip li
#     ignora grazie ai marker, quindi il file resta installabile ovunque ma
#     e' pensato per il test/build Mac.
#   - paddlepaddle invariato (stesso nome su PyPI). E' il pacchetto piu' a
#     rischio su macOS ARM: se pip fallisce qui, il resto della suite resta
#     valido e l'OCR Paddle va disabilitato con fallback doctr.
# La wheel in wheels/komic_core_rs-*-win_amd64.whl NON va installata su Mac:
# l'installer la salta (fallback Python puro), vedi installer/installer_exe.py.
#
# Uso in CI (GitHub Actions, runner macos-14 / macos-15-intel):
#   pip install -r requirements-macos.txt
